# 起源心金 4.03 HTML 存档编辑器

这是一个面向《起源心金 4.03》的浏览器版存档编辑器。应用采用单 HTML 文件交付，打开文件即可使用，不需要安装运行环境。

本项目复刻并改造自 [ggbond481/originhgss-android](https://github.com/ggbond481/originhgss-android)，在原项目的基础上改为浏览器本地运行，并针对 4.03 版本补充和调整了存档数据、道具、宝可梦、技能和界面相关功能。

特别感谢原项目作者 `ggbond481` 的研究、实现和开源工作，为本项目提供了重要的参考基础。

## 使用方式

### 直接运行

1. 下载或克隆本仓库。
2. 双击打开根目录的 `originhgss-save-editor.html`。
3. 点击“选择存档文件”，选择游戏电池存档文件。
4. 在“宝可梦”或“背包道具”模块中进行修改。
5. 点击“导出修改后的存档”生成新的存档文件。
6. 将导出的新存档放回模拟器或对应设备中测试。

支持的存档扩展名包括：

- `.dsv`
- `.sav`
- `.bin`

### GitHub Pages

本项目可以直接部署为 GitHub Pages 静态页面：

1. 打开仓库的 `Settings`。
2. 进入 `Pages`。
3. 在发布来源中选择 `Deploy from a branch`。
4. 选择 `main` 分支和根目录 `/ (root)`。
5. 保存后通过 GitHub Pages 地址打开编辑器。

## 主要功能

- 本地读取和修改《起源心金 4.03》存档。
- 队伍宝可梦编辑。
- PC 盒子管理，支持 24 个盒子。
- 宝可梦种族、等级、经验值、性格、特性、携带道具和技能编辑。
- 能力值只读显示，并根据种族、等级、个体值、努力值和性格实时计算。
- 背包道具分类、数量、添加、叠加、删除和清空。
- 道具名称、图标、技能机对应技能和招式参数展示。
- 种族、技能、特性、性格、盒子和道具列表支持搜索。
- 导出时保留原始文件，不直接覆盖用户选择的存档。

## 数据与隐私

- 存档文件只在当前浏览器页面中读取和处理。
- 存档不会通过应用上传到服务器。
- 运行所需的 4.03 数据已经内嵌到 HTML 文件中，不需要导入 ROM 才能使用。
- ROM、存档和其他个人文件不应提交到 GitHub 仓库。
- 使用前请备份原始存档，并在游戏中确认导出结果。

## 文件结构

```text
originhgss-html/
├─ originhgss-save-editor.html
├─ data/
│  └─ originhgss-4.03-data.js
├─ docs/
│  └─ feature-gap-report.md
├─ .gitignore
└─ README.md
```

- `originhgss-save-editor.html`：最终交付文件，数据和运行逻辑均已内嵌，可单独打开。
- `data/originhgss-4.03-data.js`：4.03 数据源备份，供后续维护和重新生成数据时参考。
- `docs/feature-gap-report.md`：功能差异和后续规划记录。
